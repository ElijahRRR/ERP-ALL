## 判据 1：管道全链（前端全程可见，约 15 分钟）

1. 顶栏切到作用团队 → 采集作业 → 新建（填 2-3 个任意 ASIN）→ 看到作业 pending
   （**卡 pending 是预期**：真采集引擎是 R2-01，现在没有 worker 接活）
2. 本地 AI 执行模拟回传（走真实拨入协议，数据是假的）：
   `docker compose -f infra/docker-compose.yml exec -e ERP_SIM_ENROLL_TOKEN="<令牌>" api python -m erp.tools.sim_worker`
   → 作业进度变"N成"，产品库出现产品（标题带 Demo 字样 = 模拟数据标记）
3. 产品行点「审核」→ 出 pass/reject 判定（真 LLM）→「审核详情」看命中与成本
4. 同一产品**再点一次审核**（re_audit）→ 详情里 llm_cost=0、缓存命中率 1.0（缓存判据）
5. 「分配上架」选店+build → 上架管理见 draft 且已占 GTIN（需先经 /api/docs 导入 20 枚 EAN-13）
6. 勾选提交 →（gateway_mode=dry_run）提示"已生成提交快照"——**这就是 R1 上架的终点**：
   确认提交体结构，不真发（真发能力=R2-03）
7. 点「历史」：状态链 draft→queued 完整可查
