## 二、裁定要点（云端侧转述，口径以审计侧落笔为准）

1. **产品定位改判**：多租户 → **单公司内部工具，1-2 人使用**。
2. **团队概念**：不再作为安全边界。落地建议走**冻结**而非删列：team_id 恒为单团队、
   UI 全部隐藏团队痕迹、跨团队隔离类验收判据废止；列与索引保留（惰性，无需大迁移）。
3. **角色管理**：RBAC 收缩到最简（1 管理员 + 可选只读账号）；权限表保留但停止扩展，
   角色/权限管理 UI 隐藏。
4. **插件身份**：**取消实例签发/令牌/配对/团队码**。customerId 即识别（smallbee 同形，
   考古§〇②实证其原版即无认证头）。安全前提=内网部署（RS-02a 端口收敛维持，不对公网）。
5. **派发模型**：订单→采购账号**预指派为主**（需新增指派入口）；claim-on-pull 自动
   认领降级或移除；洪水闸/首见登记在新模型下重议（预指派下「陌生 customerId」语义变了）。
6. **插件下载**：统一入口置于买家账号池页顶（13c 携带）。
7. **验证素材**：live 层验收用真实旧订单（Owner 2026-08-01，与既定 live 层规划一致）。
