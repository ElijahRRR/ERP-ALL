## 本目录放什么

每个**进入审查队列的 PR（L1/L2）**一份 `PR-<n>.md`，由**审查 AI** 落笔（L0 不审即无报告）。

## 谁不能写这里

**云端 AI 不得自写自己 PR 的审查报告。** 独立性正是这条闸的用意——它设立的直接由头就是云端侧
两次 PR 正文失实（一次写「零代码改动」、一次写「零迁移」而实际含迁移），而 Owner 的合并授权
正是基于正文。自己审自己等于把闸拆了。

本目录由云端 AI 建出空壳（2026-07-27，PR #37 走闸时发现目录尚不存在），**内容一律不由它写**。

## 审查 AI 的首要纪律（摘自 007）

**以源码为准，不以 PR 正文为准**——第一件事永远是核对正文所述与实际 diff 是否一致。
