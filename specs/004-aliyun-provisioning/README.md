# 004 阿里云资源建议配置单（EA-004）

- 日期：2026-07-10 · 作者：ar 帽 · 状态：**待 Owner 按单开通**
- 依据：D-Q46（国内阿里云）、D-Q47（云上 1 DB + 1 应用；采集 worker 在本地拨入）、D-Q37（稳定优先、DB 与应用分离）、001 §容量注记（refdata.trademark 14M 行 ≈ 15-25GB）
- 原则：起步规格够 R1-R2 用，全部选可**在线升配**的形态，不为 12 个月后的峰值提前付费。

## 1. RDS PostgreSQL（数据库，核心资产）

| 项 | 建议 | 说明 |
|---|---|---|
| 产品 | RDS PostgreSQL **16** | 不选 15 及以下 |
| 系列 | **高可用版**（双节点） | 稳定优先（D-Q37）；基础版单点省钱但不符决策 |
| 规格 | 通用型 **8 vCPU / 32GB**（如 pg.n4.4c.2m 档位按控制台实名） | 支撑日 20 万 feed_item/audit_run 写入 + trgm 检索 |
| 存储 | **ESSD PL1 500GB**，开自动扩容（阈值 80%） | refdata ~25GB + 事实表增长；PL1 够用，慢了升 PL2 |
| 必需扩展 | `pgcrypto`、`pg_trgm`、`vector`、`pg_partman`（控制台确认可用；partman 不可用则我们用 beat 自建分区，已有 fallback） | 开通后建库前先验证 `CREATE EXTENSION` |
| 备份 | 自动备份**每日** + 日志备份（WAL）开启，保留 **30 天**；每月手工快照一次长留 | 恢复演练进 R2 checklist |
| 网络 | 仅 VPC 内网访问，白名单=应用 ECS 内网 IP；**不开公网地址**（本地调试临时开+白名单 Owner IP，用完关） | |
| 账号 | 三个库账号：`erp_migrator`（DDL）/ `erp_app`（DML，受 RLS）/ `portal_app`（白名单视图） | 对应 001 §00 角色设计 |

## 2. ECS（应用服务器）

| 项 | 建议 | 说明 |
|---|---|---|
| 规格 | 通用型 g7/u1 **8 vCPU / 16GB** | 跑 api + 队列 worker×N + beat + redis + nginx（docker-compose） |
| 系统盘 | ESSD 100GB | 镜像+日志 |
| 数据盘 | ESSD 200GB | OSS 未接前落原始 payload/邮件正文/导入文件 |
| OS | Ubuntu 24.04 LTS | |
| 带宽 | 按使用流量计费，峰值 20-50Mbps | 前端静态资源小；采集大流量在本地 worker 侧不走这里 |
| 安全组 | 入：443/80（全网）、SSH 22 仅 Owner IP；出：全放 | worker 本地拨入走 443，无需入站开洞 |

Redis 跑在 ECS 容器内（00 §12：Redis 可丢可重建，不必上云 Redis 版；R3 若队列压力大再迁）。

## 3. 网络与访问

- 新建 **VPC**（如 172.16.0.0/16），RDS 与 ECS 同 VPC 同可用区（低延迟）。
- **ICP 备案注意**（D-Q46 已知问题）：国内 ECS 绑域名需备案。三选一，开通时定：
  1. 先用 `https://IP:443` + 自签/IP 证书过渡（内部系统可接受）；
  2. 有可备案域名就走备案（约 2-3 周）；
  3. 不想备案 → ECS 改买**香港地域**（RDS 同迁香港；国内访问延迟略增，采集 worker 本地拨入不受影响）。
- HTTPS：nginx + certbot（有域名）或自签（IP 过渡）。

## 4. 账号与监控

- RAM 子账号给部署用，最小权限（ECS/RDS 只读+运维必需）；主账号开 MFA。
- 云监控告警（推手机）：ECS CPU>80%/磁盘>85%、RDS CPU>70%/连接数>80%/存储>80%、RDS 主备切换事件。
- LLM API（审核用）走现有供应商 key，不在本单内。

## 5. 费用量级（按 2026 年国内牌价估，包年约 7-8 折）

| 项 | 按月估算 |
|---|---|
| RDS PG 高可用 8C32G + 500GB ESSD | ¥2,800 ~ ¥3,800 |
| ECS 8C16G + 300GB 盘 + 流量 | ¥900 ~ ¥1,400 |
| 备份/快照存储 | ¥100 ~ ¥300 |
| **合计** | **≈ ¥3,800 ~ ¥5,500 / 月** |

省钱路径（如需）：R1 期间 RDS 可先开 4C16G（≈减一半），R2#3 上量前升配——在线升配分钟级，风险低；**不建议**降为基础版单节点。
